# Code of Conduct

We are committed to a respectful, harassment-free community. Be considerate, assume good
intent while evaluating evidence, welcome different experience levels and avoid personal
attacks, discrimination, sexualized conduct, intimidation or publication of private data.

Project maintainers may edit or remove abusive content and temporarily or permanently bar
participants who violate these expectations. Report conduct issues privately through the
contact method listed in the repository security settings. Do not include sensitive user
data in a public report.
