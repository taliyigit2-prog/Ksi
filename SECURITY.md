# Security policy

Please report vulnerabilities privately through the repository's security-advisory feature.
Do not open a public issue for credentials, path traversal, SSRF, command execution, unsafe
archive/document parsing, cookie leakage or access-control bypasses.

Include the affected version, minimal reproduction, impact and whether user data is involved.
Use synthetic fixtures and redact tokens, cookies, personal URLs, disk identifiers and file
paths. Maintainers will acknowledge a report when the public repository enables advisories;
no response-time SLA is promised before the first public release.

KSI Local Studio does not accept requests to bypass DRM, CAPTCHA, paywalls or account access
controls. Supported source processing must remain within the user's access rights.
