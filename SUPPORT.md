# Support

Before requesting help, run `ksi health --json` and remove personal paths, disk identifiers,
URLs, cookies and job content from the output. Public issues should contain only a minimal
synthetic reproduction, KSI Local Studio version, macOS version and expected/actual behavior.

Model files, media, documents, private catalogs and browser profiles must never be attached.
Security-sensitive problems belong in a private security advisory, not a public issue.
