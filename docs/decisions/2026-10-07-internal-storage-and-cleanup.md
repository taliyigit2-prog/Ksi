# Internal-only final desktop revision

The user approved removal of the external-SSD runtime plan on 2026-10-07.
This decision supersedes external runtime choices in earlier desktop notes.

- The default workspace is `KSI-Workspace` below the private per-user
  `Library/Application Support/KSI Local Studio` state directory.
- GUI, CLI and MCP enforce the actual internal filesystem device. A forged
  internal selection pointing to removable/network storage is not accepted.
- Legacy external settings and original files remain private and unchanged.
  Missing old media does not prevent initializing the approved internal app.
- A populated unrelated target is never overwritten. A valid existing marker
  recovers initialization interrupted before persisting the selection.
- The ordinary settings UI reports storage without an external location picker.
- A whole `build` purge and deletion of private environment files are not
  allowed. Obsolete component stages can be removed only after an exact retained
  inventory superset and both sets of actual SHA-256 hashes are verified.
- Required offline models, corresponding sources, licenses, current binaries,
  user jobs and final outputs stay protected. No new features are added.

This source checkpoint is not final product acceptance. Archive privacy review,
legacy job-path migration, complete native apps, installation media and actual
cross-architecture automatic acceptance still need recorded evidence.
