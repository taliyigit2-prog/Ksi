# KSI Local Studio glossary

- **KSI Core:** Shared application services used by GUI, CLI and MCP.
- **Workspace:** The `KSI-Workspace` directory on the selected external disk.
- **State directory:** Private internal metadata under macOS Application Support.
- **Provider:** A component that inspects or acquires an external source.
- **Engine:** A local processor such as transcription, translation or imaging.
- **Job:** A resumable user operation recorded in SQLite.
- **Artifact:** A user-visible output such as a video, subtitle, PDF or image.
- **Optional pack:** A model or external tool not required by the core install.
